# TVmaze API — конспект

Базова адреса API: `https://api.tvmaze.com`

| Питання | Що каже документація | Що показав запит (адреса) |
|---|---|---|
| Ендпоїнт пошуку за назвою, параметри | `GET /search/shows?q=:query`. Параметр `q` містить назву серіалу. Пошук допускає невеликі помилки в назві та повертає результати за релевантністю. | Адреса: `https://api.tvmaze.com/search/shows?q=girls`. Очікуваний результат: масив об'єктів із полями `score` та `show`. Перевірити у Network. |
| Форма відповіді пошуку | Кожен елемент масиву містить `score` — оцінку відповідності та `show` — об'єкт із даними серіалу. У `show` є, зокрема, `id`, `name`, `summary`, `genres`, `image`. | Адреса: `https://api.tvmaze.com/search/shows?q=girls`. Перевірити у вкладці Preview або Response структуру одного елемента масиву. |
| Ендпоїнт серіалу; як отримати епізоди й акторів одним запитом | Основна інформація: `GET /shows/:id`. Пов'язані дані можна отримати через параметр `embed`, наприклад `embed[]=episodes&embed[]=cast`. | Адреса: `https://api.tvmaze.com/shows/82?embed%5B%5D=episodes&embed%5B%5D=cast`. Перевірити, що у відповіді є основні дані серіалу й вкладені дані `episodes` та `cast`. |
| Поля серіалу, що можуть бути `null` (з прикладом серіалу) | Деякі поля залежать від наявності даних. Наприклад, `image`, `network`, `officialSite` або `ended` можуть бути `null`. Необхідно перевіряти значення перед відображенням. | Адреса: `https://api.tvmaze.com/shows/82`. У відповіді знайти поле зі значенням `null` і записати його назву та значення. Якщо в цього серіалу такого поля немає, перевірити інший результат пошуку. |
| Що повертає пошук без результатів | Ендпоїнт пошуку повертає масив. Якщо збігів немає, масив порожній; це не те саме, що помилка HTTP 404. | Адреса: `https://api.tvmaze.com/search/shows?q=zzzxxyy_no_such_show_987654`. Очікуваний результат: `[]`. Перевірити статус у Network. |
| Що повертає неіснуючий id | Ендпоїнт `/shows/:id` повертає HTTP 404, якщо серіал із таким ID не знайдений. | Адреса: `https://api.tvmaze.com/shows/999999999`. Очікуваний результат: статус `404`. Перевірити тіло відповіді у Network. |
| Ліміт запитів і що робити на 429 | Документація вказує щонайменше 20 запитів за 10 секунд на IP-адресу. При перевищенні можливий статус `429`. Рекомендація — зачекати кілька секунд перед повтором запиту. | Адреса: `https://api.tvmaze.com/shows/82`. Один запит не обов'язково викличе 429. Ліміт і реакцію на 429 описано в документації; не потрібно навмисно надсилати багато запитів. |
| Кешування: що кешує TVmaze і що — браузер | HTTP-відповіді TVmaze кешуються на балансувальниках приблизно 60 хвилин. Браузерний кеш залежить від HTTP-заголовків відповіді, зокрема `Cache-Control`. | Адреса: `https://api.tvmaze.com/shows/1`. У Network перевірити `Cache-Control` та Size. Повторити запит і подивитися, чи використано кеш; результат залежить від заголовків і стану кешу браузера. |
| CORS: що обіцяє документація і що показав експеримент 12 | Документація заявляє, що ендпоїнти API підтримують CORS. Запит із несейфлістовим заголовком може спричинити попередній `OPTIONS` preflight; сервер має дозволити метод і заголовки. | Адреса API: `https://api.tvmaze.com/shows/82`. В експерименті 12 порівняти запит із `Content-Type: application/json` та запит із `Accept: application/json`. У Network перевірити, чи був `OPTIONS`, його статус і результат основного запиту. |
| Ліцензія й атрибуція | TVmaze API використовує ліцензію CC BY-SA. Джерело потрібно зазначати, наприклад, посиланням на TVmaze у застосунку; також необхідно дотримуватися умов ShareAlike. | Документація: `https://www.tvmaze.com/api`. Перевірити розділ Licensing. У застосунку передбачити посилання на TVmaze як джерело даних. |
