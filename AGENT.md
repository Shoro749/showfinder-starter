# AGENTS.md — правила ShowFinder

## TVmaze API
- Використовуй лише Fetch API та `https://api.tvmaze.com`.
- Пошук: `GET /search/shows?q=<query>`. Перед запитом прибирай пробіли по краях і кодуй параметр через `URLSearchParams` або `encodeURIComponent`.
- Пошук повертає масив `{ score, show }`. Для `renderResults` передавай масив об'єктів `show` у початковому порядку.
- Дані серіалу: `GET /shows/:id`. Епізоди й актори отримуй через документовані ендпоїнти або `embed`.
- Перевіряй `response.ok`: HTTP-помилки не є успішними даними. `404` означає, що серіал не знайдено; `429` — перевищення ліміту; `5xx` — помилка сервера.
- TVmaze допускає щонайменше 20 запитів за 10 секунд з однієї IP-адреси. На `429` зачекай 2–5 секунд і повтори запит лише один раз.
- API підтримує CORS. Не додавай непотрібних заголовків, `Content-Type` для GET або `mode: "no-cors"`.

## Правила проєкту
- Зберігай наявні HTML-ідентифікатори й використовуй `renderResults` та `renderShow` із `src/view.js`.
- Пошук має debounce: один запит після завершення серії введень, із затримкою до 500 мс. У цьому проєкті використовуй 450 мс, а попередній таймер скасовуй через `clearTimeout`.
- Enter запускає пошук одразу, без перезавантаження сторінки й дубльованого запиту.
- Не дозволяй старим відповідям замінювати результати новішого запиту. Скасовуй непотрібні запити та коректно обробляй скасування.
- Під час завантаження встановлюй `aria-busy="true"` і показуй потрібний стан. Після завершення або помилки прибирай стан завантаження.
- Не змінюй `check.html`, теку `check/`, `offline.html` та `src/view.js`.
- Не додавай бібліотек, фреймворків, CORS-проксі, `alert()`, `confirm()` або `prompt()`.
- Не показуй користувачеві технічні помилки. Обробляй їх і показуй повідомлення, передбачені ТЗ.
- Після змін запускай `check.html` і перевіряй, що новий функціонал не ламає попередні тести.
- Якщо перевірка падає лише під час першого запуску, повтори її після перезавантаження. Не вважай проблему виправленою без стабільного результату.
- Перед змінами пояснюй план. Не редагуй захищені файли й не переписуй непов'язані частини проєкту.
