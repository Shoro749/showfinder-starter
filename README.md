# ShowFinder — starter-проєкт для ЛР №11

Пошук серіалів через [TVmaze API](https://www.tvmaze.com/api): результати, сторінка серіалу
з епізодами й акторами, стани завантаження й помилок. HTML, CSS, шаблони станів і модуль
показу даних уже готові. Запити до API й поведінка застосунку — порожні: їх і треба написати
в лабораторній роботі.

Опис завдання та специфікація:
<https://denysmatsevych.github.io/web-development-2026/web-development/labs/lab-11/> і
<https://denysmatsevych.github.io/web-development-2026/web-development/labs/lab-11/task/>.

## Склад

```text
index.html         статична розмітка: форма пошуку, статус, #results, #details, шаблони станів
styles.css         стилі, зокрема станів і [aria-busy="true"]
src/view.js        показ даних TVmaze: renderResults і renderShow — наданий, не змінюється
src/main.js        точка входу
src/api.js         запити до TVmaze
src/app.js         пошук, сторінка серіалу, стани завантаження й помилок
check.html         самоперевірка; її код — у check/, записані відповіді TVmaze — у check/fixtures/
offline.html       той самий застосунок на записаних відповідях, без мережі
experiments.html   сторінка для експериментів §4
```

Функції в `src/api.js` і `src/app.js` поки що порожні, тож сторінка відкривається без помилок,
але нічого не шукає. Розподіл за файлами — лише пропозиція: структуруйте код як вважаєте за
потрібне, але `src/view.js`, `check.html`, `check/` і `offline.html` не змінюйте в жодному
коміті.

## Як запустити

Відкрийте `index.html` через **Live Preview** у VS Code (або `npx serve .`) у Chrome або
Edge. Через `file://` сторінка не запрацює: браузер не завантажує звідти ES-модулі.
`npm install` не потрібен. Застосунок звертається до справжнього `https://api.tvmaze.com`, тож
потрібен інтернет.

## Самоперевірка

Відкрийте `check.html` так само, як `index.html`. Сторінка завантажує застосунок у фрейм,
працює з ним як користувач (вводить запит, натискає Enter, клікає) і показує кожне правило ТЗ
як ✓ або ✗, а внизу — «Пройдено: N з M». На запити до TVmaze вона відповідає сама,
записаними відповідями API: затримує їх, повертає помилки або обриває з'єднання. Тому вона не
залежить ні від мережі, ні від ліміту запитів. Код застосунку перевірка не читає.

Перевірка триває близько хвилини: правила про debounce і 429 чекають у реальному часі. На
початку всі перевірки падають; повідомлення під ✗ пояснює, що саме не так. Справжній TVmaze,
справжню помилку CORS і панель Network перевірка не бачить: для них є чек-лист Network у ТЗ.

## Офлайн-режим

`offline.html` відкриває той самий `index.html`, але запити до TVmaze отримують записані
відповіді з `check/fixtures/` через 0,25–0,9 с. Він для заняття: уся аудиторія виходить в
інтернет з однієї IP-адреси, і TVmaze може відповідати `429`. Записано кілька пошуків
(`girls`, `gir`, `law & order`, `doctor`, `star`, `dark`), а повні сторінки з епізодами й
акторами — для шести серіалів; інші серіали відкриваються без епізодів. Для чек-листа Network
потрібен `index.html` зі справжнім API.

## Як задеплоїти

Вміст цієї теки можна покласти або в **окремий репозиторій**, або в теку `lab-11/` спільного
репозиторію з лабораторними. Усі шляхи в проєкті відносні, тому він працює і з кореня сайту,
і з підтеки. Самоперевірка — за адресою сторінки з `check.html` у кінці.

### GitHub Pages

1. Завантажте файли в репозиторій.
2. Settings → Pages → Source: _Deploy from a branch_, гілка `main`, тека `/`.
3. Сторінка з'явиться за адресою `https://<username>.github.io/<repository>/`
   (або `…/<repository>/lab-11/`).

### Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → імпорт репозиторію.
2. Framework Preset: **Other**. Build Command і Output Directory залиште порожніми — збирати
   нічого не потрібно.
3. Якщо проєкт лежить у теці `lab-11/` — **Root Directory → `lab-11`**.
4. Сторінка з'явиться за адресою `https://<project>.vercel.app/`.

`check/fixtures/` — адаптація відповідей TVmaze API, отриманих 13.10.2026: результати пошуку
для шести запитів і дані шести серіалів з епізодами й акторами, де залишено лише поля, які
показує застосунок. Які запити записано й що саме скорочено, вказано в полі `changes` кожного
файлу. Ця адаптація — за тією самою ліцензією CC BY-SA 4.0.
